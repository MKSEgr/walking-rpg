# ADR-0003: принцип Walk now, play later

- **Статус:** Accepted
- **Дата:** 2026-07-25

## Контекст

Постоянное взаимодействие с телефоном во время ходьбы ухудшает безопасность, расход батареи и качество самой прогулки.

## Решение

Основной игровой цикл проектируется так, чтобы пользователь выбирал цель до прогулки и разбирал результат после неё. Действия во время движения не должны быть обязательными.

## Последствия

- события могут разрешаться асинхронно;
- UI главного экрана должен показывать ясный отложенный результат;
- GPS не требуется для MVP;
- игровые механики, требующие постоянного foreground, считаются исключением.

## Условия пересмотра

Только после пользовательского исследования и отдельной оценки безопасности.
