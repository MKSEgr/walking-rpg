# ADR-0002: Java для backend

- **Статус:** Accepted
- **Дата:** 2026-07-25

## Контекст

Первоначально рассматривался Kotlin. Основной разработчик проекта специализируется на Java. Команда состоит из двух участников, поэтому скорость отладки, знакомая экосистема и возможность самостоятельно поддерживать код важнее уменьшения объёма синтаксиса.

## Решение

Использовать Java 21 и Spring Boot 4.1.x. Maven — система сборки.

## Последствия

- backend может полностью поддерживаться основным разработчиком;
- снижается стоимость переключения контекста;
- примеры и генерация кода должны быть Java-first;
- Kotlin допускается только для Android platform bridge, если он потребуется.

## Условия пересмотра

Решение может быть пересмотрено только при конкретной измеримой выгоде, а не ради стилистических предпочтений.
