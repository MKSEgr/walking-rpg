# ADR-0001: монорепозиторий и модульный монолит

- **Статус:** Accepted
- **Дата:** 2026-07-25

## Контекст

Проект разрабатывается двумя участниками. Отдельные репозитории и микросервисы увеличат стоимость координации, сборки, версионирования и локального запуска до появления реальной нагрузки.

## Решение

Использовать один репозиторий с каталогами `backend`, `mobile`, `docs` и `scripts`. Backend развивать как модульный монолит.

## Последствия

Плюсы:

- единая версия контрактов;
- простой локальный запуск;
- атомарные вертикальные изменения;
- меньше инфраструктуры.

Минусы:

- необходимо следить за границами модулей;
- будущий вынос сервиса потребует явной миграции.

## Условия пересмотра

Решение пересматривается при доказанной необходимости независимого масштабирования, отдельного владения или независимого релизного цикла.
