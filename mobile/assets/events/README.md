# Expedition event scenes

These landscape WebP assets define the first server-authored event-scene
vocabulary for the soft science-fantasy frontier. Each scene keeps its focal
silhouette inside the middle of the frame so `BoxFit.cover` remains safe in
compact and wide mobile cards.

| Asset | Stable event identity | Visual role |
|---|---|---|
| `signal_source.webp` | `signal-source-v1` | outer beacon and repeating signal |
| `echo_vault.webp` | `echo-vault-v1` | unstable archive core and two responses |
| `mirror_delta.webp` | `mirror-delta-v1` | reflected fork and hidden current |
| `resonance_pocket.webp` | `resonance-pocket-v1` | converging routes inside folded space |

The client selects a scene only from the exact stable `eventId`. Unknown IDs
retain a neutral code-native signal field. Title, summary, status, choices,
requirements, rewards, route access and command behavior remain entirely
server-owned.
