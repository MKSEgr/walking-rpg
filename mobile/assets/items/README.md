# Expedition item illustrations

These square WebP assets define the first illustrated item vocabulary for the
soft science-fantasy frontier. They share a night-ink vignette, painterly
material treatment and strong silhouette intended to remain distinct at
`56-72 px`.

| Asset | Stable presentation identity | Visual role |
|---|---|---|
| `lumen_shard.webp` | `lumen-shard` | lumen crystal with an ENERGY core |
| `echo_thread.webp` | `echo-thread` | braided resonance signal filament |
| `resonance_compass.webp` | `resonance-compass` | crafted navigation instrument |

The images are presentation only. Name, description, quantity, availability,
crafting status, equipment state and rewards remain server-authoritative. The
client selects art only from an exact stable `itemId`; unknown IDs keep the
code-native fallback and never inherit art from a matching display name.

## Artwork provenance

- created for this repository with OpenAI image generation on 2026-08-04;
- generated as three coordinated game UI item illustrations using the approved
  Ink, Deep water, Lumen, ENERGY, Resonance and Moon mist palette;
- production prompts required one centered text-free silhouette, a quiet
  frontier vignette, small-size readability and no character, weapon, GPS,
  fitness, currency, loot-box, logo or watermark treatment;
- the generated `1254 x 1254` sources were reviewed together at `72 px`, then
  resized and optimized to the committed `512 x 512` WebP assets.
